# 12 USAGE WATCHER

Powers the in-app meter: live burn rate, remaining credits, active brain, per-bot spend. Tags every API call. Polls the OpenAI dashboard on a schedule. Branch: fleet/usage-watcher/meter.

Meter spec: compact strip in the command center shell, near top or side. Shows live burn, remaining credits, active brain, heaviest bot. Tap expands to full breakdown: per bot, per provider, per session. Glanceable during speak without leaving voice view.
