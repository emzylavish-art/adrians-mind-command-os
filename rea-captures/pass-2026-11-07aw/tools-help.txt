=== rea.py --help ===
usage: rea.py [-h] [--json] [--out OUT] [path]

REA (Reverse Engineer Anything): offline repository reconnaissance utility.
Scans a user-selected directory for file inventory, language distribution,
likely entrypoints, dependency manifests, and security-relevant markers. It
does not execute discovered code or contact external systems.

positional arguments:
  path        directory to inspect

options:
  -h, --help  show this help message and exit
  --json      emit JSON
  --out OUT   write report to a file

=== security_review.py --help ===
usage: security_review.py [-h] [--json] [--out OUT] [path]

Defensive static security review for repository-owned source files. This first
version intentionally performs local, offline checks only. It does not run
target code, probe hosts, exploit findings, or print matched secret values.

positional arguments:
  path        Repository directory or source file

options:
  -h, --help  show this help message and exit
  --json      Emit JSON
  --out OUT   Optional output path
