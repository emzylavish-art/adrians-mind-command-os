# Hatchet

Candidate id: hatchet. Name: Hatchet. Classification: blocked-by-security. This note does not approve or install it.

Official source: [hatchet-dev/hatchet](https://github.com/hatchet-dev/hatchet). The repository is public, not archived, and not disabled. Its homepage field is [https://hatchet.run](https://hatchet.run/). The README describes an orchestration engine for background tasks, AI agents, and durable workflows, and it points to [Hatchet Cloud](https://cloud.hatchet.run/) and [docs.hatchet.run](https://docs.hatchet.run/). The LICENSE copyright holder is Hatchet Technologies Inc. This is the official hatchet-dev project. No git tag starting with `v2` was present. The site announcement titled Hatchet v2, dated 2026-11-09, is a product announcement, not an engine tag.

Version: the newest engine tag seen is `v0.120.5`, commit `0787e45d149590e93da59b1c8c1638fb451d8cda`, committed 2026-11-13T19:15:26Z, message `fix: one more source of dag crash looping (#5510)`. That tag has no GitHub release object. GitHub `releases/latest` is `v0.114.2`, published 2026-10-26T15:00:17Z, not a draft and not a prerelease. That release commit is `4bba49661c0dfd0f500c07a0ab768112eaafd881`, committed 2026-10-26T14:50:39Z. `CHANGELOG.md` on both `main` and `v0.120.5` starts at 0.114.2, so the changelog does not describe the tags after that release. At check time `main` was six commits ahead of `v0.120.5`, at `ee6d34ecd0baf10908a1a621b9b5324721026f25`, dated 2026-11-14T20:17:03Z. Those commits are not the candidate tag. SDK releases are also not the engine. npm `@hatchet-dev/typescript-sdk` latest is 1.47.2, published 2026-11-13T20:51:05.221Z. PyPI `hatchet-sdk` latest is 1.46.0, uploaded 2026-11-13T18:50:32Z. A later `main` commit says `feat(python): 2.0.0 (#3545)`, but that is not the published PyPI version.

License: MIT, copyright 2023-present Hatchet Technologies Inc. The LICENSE file at tag `v0.120.5` matches the MIT text. The published TypeScript package 1.47.2 and Python package 1.46.0 also say MIT. The license allows use, modification, and sale if the copyright and permission notice stay with copies. It gives no warranty. That is not a license block.

Commercial: the engine is free to self-host under MIT. Hatchet Cloud is a separate paid service. On 2026-11-15 the pricing page listed a no-card pay-as-you-go column at 2,000 task runs a day, 2,000 events a day, 10 workers, 1 tenant, 3 users, and 1 day of retention. The card-on-file column included 1 million runs and 1 million events a month, then $30 per million runs and $5 per million events, with 100 workers, 10 tenants, 50 users included and then $10 per user, and 7-day retention. Active storage above 10 GB was listed at $0.03 per GB-hour on that column. Custom pricing covered high volume, dedicated capacity, SSO, HIPAA, and self-hosted or bring-your-own-cloud support. The homepage said the first million runs and events are free with no card. That sentence does not match the no-card column on the same day's pricing table. Exact Adrian Mind usage is unverified. This research created no account and spent no money.

Activity: at check time the GitHub repository showed 8,286 stars, 536 forks, and an open-issue count of 142. That count includes pull requests. `created_at` was 2023-12-15T17:50:29Z. `pushed_at` was 2026-11-14T22:21:02Z. npm recorded 514,088 downloads of `@hatchet-dev/typescript-sdk` from 2026-11-08 through 2026-11-14. The site says Hatchet Technologies Inc. The v2 announcement identifies Alexander Belanger as co-founder and CEO and says Hatchet is YC W24. That biography was not separately checked against Y Combinator.

Runtime: Go control plane with a PostgreSQL durability layer. Workers are long-running processes in TypeScript, Python, Go, or Ruby. The docs also describe an optional RabbitMQ queue, a dashboard, cron and schedules, retries, and durable tasks. Self-hosting is Docker Compose, a single `hatchet-lite` image, or Helm. The documented local path is the Hatchet CLI, which requires Docker, or Hatchet Cloud. The TypeScript SDK is the closest library to this product. Package 1.47.2 has engines `node >= 22` and no bin. None of this was executed.

Install size: not measured on disk, because nothing was installed or pulled. The `v0.114.2` Linux x86_64 release archive is 13,460,063 bytes. The same release has Linux arm64 at 12,359,366 bytes and Windows x86_64 at 13,829,402 bytes. Tag `v0.120.5` has no release asset, so its binary size is unverified. The published npm package reports an unpacked size of 3,281,706 bytes across 838 files. The PyPI 1.46.0 wheel is 728,450 bytes. Those figures do not include PostgreSQL, Docker, or the TypeScript peer `zod`. GitHub reports the repository size as 225,104 KB. That is not an installed footprint.

Dependencies: self-hosting requires PostgreSQL. The lite example uses `postgres:15.6`. RabbitMQ is optional. The CLI path requires Docker. At tag `v0.120.5`, `go.mod` says Go 1.26.10. The TypeScript 1.47.2 record depends on `qs`, `long`, `yaml`, `axios`, `nice-grpc`, `protobufjs`, `@bufbuild/protobuf`, and ConnectRPC packages. The only required peer is `zod` `^3.25.0 || ^4.0.0`. OpenTelemetry, gRPC, MCP, and agent SDK peers are optional. The published scripts include `prepublish`. They do not include `preinstall`, `install`, or `postinstall`. Transitive dependency risk was not audited.

Security: GitHub lists a medium advisory, [GHSA-9m9j-69qf-2pgc](https://github.com/hatchet-dev/hatchet/security/advisories/GHSA-9m9j-69qf-2pgc), for session fixation in `SaveAuthenticated`. It was published 2026-11-12T13:22:11Z, is not withdrawn, and records the vulnerable range as `All`. The patched-version field is empty. The current tag is inside that published range, and no patched release is named. A low advisory, [GHSA-2m5w-442c-7fg3](https://github.com/hatchet-dev/hatchet/security/advisories/GHSA-2m5w-442c-7fg3), says `hatchet profile create` and `update` can silently persist plaintext gRPC and then keep sending the tenant token in the clear. Its recorded range is `v0.107.2`, also with an empty patched-version field. Whether that range means only 0.107.2 is unverified, so it is not treated as covering 0.120.5. Older published advisories name patches before this tag, including high [GHSA-phg3-3g28-wq9v](https://github.com/advisories/GHSA-phg3-3g28-wq9v) patched in v0.91.2 and medium [GHSA-992g-9cr3-vm5x](https://github.com/advisories/GHSA-992g-9cr3-vm5x) patched in 0.106.1. No new vulnerability scan was run. Whether source after those dates changes the two November 12 findings is unverified, because the advisory records themselves do not name a fix release.

Secrets: a worker needs an unrestricted tenant token, documented as `HATCHET_CLIENT_TOKEN`. Self-hosting uses `DATABASE_URL` and auth cookie settings. The lite guide publishes a default login of `admin@example.com` with password `Admin123!!`. No secret was read or written for this check. The official CLI installer is a remote shell script. It was not run.

Integration: Adrian Mind does not import Hatchet. The product `package.json` has no Hatchet dependency, and a repository search outside `node_modules`, `.git`, and `upstream` found no Hatchet reference. Adding it would be a new control plane plus a worker, not an upgrade of Chat, Build, or Speak. It was not added.

Compatibility: the product TypeScript range is `^5.7.0` and `zod` is `^4.4.0`, which satisfies the published TypeScript peer range. The product manifest has no `engines` field. The sandbox Node is v22.23.4, which meets the SDK's `>=22`. Whether a gRPC worker can run inside the current Vite preview is unverified. The preview would still need either Hatchet Cloud or a self-hosted engine with PostgreSQL. The docs say workers can be pointed at either. That was not tested.

Risks: the engine persists task inputs, outputs, logs, and retries. A later trial can retain private conversation data outside the current preview database. The published session-fixation advisory covers every recorded version and names no patch, so the dashboard should not be treated as safe for a shared cookie domain. The documented lite image ships a known admin password and an insecure cookie setting for localhost. The official quickstart pipes a remote script into a shell. `main` is six commits ahead of `v0.120.5`, and the changelog stops at 0.114.2, so the newest tag is not the same thing as the latest GitHub release. No code review of either version was done.

Maintenance: Hatchet Technologies Inc publishes the repository. The newest tag was 2026-11-13, and `main` moved again on 2026-11-14. SECURITY.md says security and bug fixes are provided for the current major version, with high and critical findings able to force a patch. Support beyond that policy page is unverified. The v2 announcement says the core engine remains MIT-licensed. That is a company statement, not a contract.

Rollback: do not add `@hatchet-dev/typescript-sdk` or `hatchet-sdk`, and do not start the CLI, Docker image, or Cloud tenant. If a later trial does, stop that process, remove the added package from the manifest, and delete the local PostgreSQL volume or Cloud tenant created for the trial. Nothing was installed, so there is no package or container to remove.

Classification: blocked-by-security. Identity is confirmed. The MIT license does not block review. The published session-fixation advisory covers all versions and names no patched release, so this candidate is not clear for a trial. It is not approved and not installed.
