# WeKnora

Candidate id: weknora. Name: WeKnora. Classification: evaluation-only. This note does not approve or install it.

Official source: [Tencent/WeKnora](https://github.com/Tencent/WeKnora). The repository is public, not a fork, not archived, and not disabled. Its homepage field is [https://weknora.weixin.qq.com](https://weknora.weixin.qq.com/). That site calls itself Tencent Open Source WeKnora and links back to the same GitHub repository. The README describes an open-source LLM knowledge framework for document understanding, retrieval, reasoning, and a self-maintaining wiki. This is the official Tencent project. It was not cloned.

Version: GitHub `releases/latest` is `v0.9.0`, published 2026-10-29T06:59:12Z, not a draft and not a prerelease. The tag points at commit `f17ee8a8da901bd658a4cb25f40b5fd41adbfdd7`, committed 2026-10-29T06:57:29Z, message `docs: finalize v0.9.0 release notes and upgrade guidance (#4864)`. The `VERSION` file at that tag contains `0.9.0`. The release has no uploaded binary assets. Source tarball and zipball URLs exist. At check time `main` was 207 commits ahead of `v0.9.0`, at `cbdcebabf48c5ee2d6868b370326aa8341703f62`, dated 2026-11-09T15:19:49Z. Those commits are not the candidate release. Docker Hub tags `wechatopenai/weknora-app:v0.9.0`, `wechatopenai/weknora-ui:v0.9.0`, and `wechatopenai/weknora-docreader:v0.9.0` were pushed on 2026-10-29. They were not pulled.

License: the `LICENSE` file at tag `v0.9.0` says WeKnora is licensed under the MIT except for listed third-party components, copyright 2026 Tencent. The MIT text allows use, modification, and sale if the copyright and permission notice stay with copies. It gives no warranty. The official site footer also says MIT License. GitHub's license API still returns SPDX `NOASSERTION` and name `Other`, because the file is a Tencent wrapper rather than a bare MIT file. Third-party notices at the same tag include MPL-2.0 for `github.com/go-sql-driver/mysql` v1.10.0 and `github.com/shoenig/go-m1cpu` v0.1.6, Apache-2.0 for OpenCC dictionary data, RapidOCR, and OpenCV, MIT for ONNX Runtime and Wails, and BSD-3-Clause for NumPy. The notice says GPL-licensed `cedar-go` code is not included. That combination is not a license block for reading or a private evaluation. Whether every vendored file matches those notices was not audited.

Commercial: self-hosting the MIT project does not require a WeKnora subscription. The site also offers the WeChat Dialog Open Platform and a Tencent Cloud Lighthouse application template. Those are separate Tencent services. Their current prices were not verified. The v0.4.0 changelog mentions WeKnora Cloud as hosted LLM and parsing. Current Cloud terms and prices are unverified. Exact Adrian Mind usage is unverified. This research created no account and spent no money.

Activity: at check time the GitHub API showed 37,319 stars, 5,172 forks, 151 subscribers, and an open-issue count of 987. That count includes pull requests. `created_at` was 2025-07-22T08:01:23Z. `pushed_at` was 2026-11-09T15:19:50Z. The repository page listed 4,006 commits. The owner is the Tencent organization. The default branch is `main`. Primary language is Go.

Runtime: a Go 1.26.0 backend, a Vue frontend, and a Python 3.10 document-reader service. Standard deployment is Docker Compose or Helm on Kubernetes 1.25 or newer. Compose uses ParadeDB `paradedb/paradedb:v0.25.11-pg17`, Redis 7.0, and Asynq. The web UI listens on host port 80 by default. The API listens on host port 8080 by default. A Lite mode uses one binary, SQLite, and an in-memory queue. The desktop app is documented as not formally released and has no installer on the current GitHub release. None of this was executed.

Install size: not measured on disk, because nothing was cloned, pulled, or installed. Docker Hub reports compressed image sizes for `v0.9.0`: `weknora-app` linux/amd64 is 583,736,787 bytes and linux/arm64 is 549,673,003 bytes; `weknora-ui` linux/amd64 is 33,717,016 bytes and linux/arm64 is 33,598,142 bytes; `weknora-docreader` linux/amd64 is 1,672,232,998 bytes and linux/arm64 is 1,590,570,423 bytes. Those figures exclude ParadeDB, Redis, model weights, and knowledge-base files. GitHub reports the repository size as 259,467 KB. That is not an installed footprint.

Dependencies: the documented standard path needs Docker 20.10 or newer and Docker Compose v2. It also needs a model API or a separate Ollama process. Source builds need Go 1.26, CGO, Node.js and npm, and Python 3.10 with uv for docreader. Optional profiles add Neo4j, MinIO, Qdrant, Milvus, Weaviate, Doris, SearXNG, and Langfuse. The official guide says the first deploy must set `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `REDIS_PASSWORD`, `JWT_SECRET`, and a 32-byte `SYSTEM_AES_KEY`. `go.mod` at `v0.9.0` declares module `github.com/Tencent/WeKnora` and Go 1.26.0. Transitive dependency risk was not audited.

Security: the repository security API returned 10 published advisories, none withdrawn. The newest named patch among them is 0.3.2, for high [GHSA-ccj6-79j6-cq5q](https://github.com/Tencent/WeKnora/security/advisories/GHSA-ccj6-79j6-cq5q), range `<= 0.3.1`. The other ranged advisories stop at 0.3.0, 0.2.12, 0.2.10, or earlier. [GHSA-pcwc-3fw3-8cqv](https://github.com/Tencent/WeKnora/security/advisories/GHSA-pcwc-3fw3-8cqv) records range `<0.2.4` with an empty patched-version field. [GHSA-78h3-63c4-5fqc](https://github.com/Tencent/WeKnora/security/advisories/GHSA-78h3-63c4-5fqc) records range `< 0.2.5`, also with an empty patched-version field. Those ranges do not cover `v0.9.0`. No advisory in that list names `v0.9.0` as vulnerable. No new vulnerability scan was run. `SECURITY.md` asks for private reporting and aims to acknowledge a report within 48 hours. It does not state a supported-version window.

Secrets: a real deployment needs database, Redis, JWT, and AES key material, plus whatever model or connector keys the operator adds. Compose documents default optional credentials of `minioadmin` / `minioadmin` and Neo4j `neo4j` / `password`. Registration is open unless `DISABLE_REGISTRATION` is set. The compose file says mounting the Docker socket is equivalent to host root and leaves that mount commented out. No secret was read or written for this check. The official start path is `make start-all` or `docker compose`, not a remote shell installer.

Integration: Adrian Mind's `package.json` has no WeKnora dependency. `tools/bootstrap/extended-upstream.json` already pins `Tencent/WeKnora` at `d9c1cf65f0d8ad56e11a1c6340b635e4fede107c`, committed 2026-11-02T11:16:58Z, and marks it `not-connected`. That pin is later than tag `v0.9.0` and earlier than the current `main` tip. `.gitmodules` names the same repository. The checkout is not present in this sandbox under `upstream/WeKnora`. Docs say the source checkout is not a running service. Adding a live WeKnora stack would be a separate service, not an upgrade of Chat, Build, or Speak. It was not added.

Compatibility: this product is TypeScript on the Vite preview at port 8080. WeKnora's standard API also defaults to port 8080, so a trial on this machine would collide with the preview unless `APP_PORT` changes. The product manifest has no `engines` field and does not import the Go module. ParadeDB from `v0.22.6-pg17` documents an `x86-64-v2` CPU baseline. Whether this sandbox CPU meets that baseline is unverified, because no image was started. The pinned submodule commit is not the same commit as `v0.9.0` or current `main`.

Risks: the product stores uploaded documents, model credentials, and chat history. A later trial can retain private conversation data outside the current preview database. The agent can operate the user's Chrome or Edge through BrowserSkill, install skills from ClawHub, SkillHub, Git, or ZIP, and run sandboxed commands. The v0.8.2 notes say sandbox commands run as `root`. Docker socket access is documented as host-root equivalent. Open registration is the default. `main` is 207 commits ahead of the latest release, so the newest source is not the same thing as `v0.9.0`. No code review of either version was done.

Maintenance: Tencent publishes the repository. The latest release was 2026-10-29, and `main` moved again on 2026-11-09. The security policy names no support contract. Paid support is unverified.

Rollback: do not pull the Docker images, do not run Compose or Helm, and do not start the Lite binary. If a later trial does, stop that compose project, remove only the volumes created for it, and free ports 80 and 8080 so the Adrian preview can bind 8080 again. The existing submodule pin should stay not-connected. Nothing was installed for this check, so there is no package or container to remove.

Classification: evaluation-only. Identity is confirmed. The MIT grant, with the named third-party notices, does not block a private reading or evaluation. The published advisories do not cover `v0.9.0`. It is not approved and not installed.
