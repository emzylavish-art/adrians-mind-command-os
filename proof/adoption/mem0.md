# Mem0

Candidate id: mem0. Name: Mem0. Classification: evaluation-only. This note does not approve or install it.

Official source: [mem0ai/mem0](https://github.com/mem0ai/mem0). The repository is public, not a fork, not archived, and not disabled. Its homepage field is [https://mem0.ai](https://mem0.ai/). The site links release notes and GitHub back to that same repository. The README calls Mem0 the memory layer for AI agents and points to [docs.mem0.ai](https://docs.mem0.ai/) and [app.mem0.ai](https://app.mem0.ai/). Y Combinator lists the company as Mem0, Summer 2024, active, at [https://mem0.ai](https://mem0.ai/), with GitHub [https://github.com/mem0ai/](https://github.com/mem0ai/) and founders Taranjeet Singh and Deshraj Yadav. The LICENSE appendix names Taranjeet Singh. This is the official mem0ai project. OpenMemory, the CLI, and the hosted MCP server are related surfaces, not a different candidate.

Version: GitHub `releases/latest` is `ts-v3.3.1`, named Mem0 Node SDK (v3.3.1), published 2026-09-25T17:36:35Z, not a draft and not a prerelease. The Python release on the same commit is `v2.2.1`, published the same day. Both tags point at commit `94c3fe9f238f3dbf29c9ce98643bd71eb13077cd`, committed 2026-09-25T17:34:12Z, message `chore(release): bump Python SDK to 2.2.1 and TypeScript SDK to 3.3.1 (#7456)`. PyPI `mem0ai` 2.2.1 was uploaded 2026-09-25T17:36:07Z and is not yanked. npm `mem0ai` 3.3.1 records the same git commit. Those published packages are the candidate. `main` is not the candidate. At check time `main` was 14 commits ahead of `v2.2.1`, at `f1791daa86d469249c9b002f62644d58a1eb96a0`, dated 2026-11-06T16:53:06Z. `pushed_at` was 2026-11-06T16:53:07Z. Plugin tags such as `pi-agent-v0.3.2` are also not the SDK.

License: Apache-2.0. GitHub reports SPDX `Apache-2.0`. The LICENSE file on `main` is the Apache License 2.0 text, and its appendix copyright is 2023 Taranjeet Singh. PyPI 2.2.1 and npm 3.3.1 both say Apache-2.0. The license allows use, modification, and commercial distribution if the license, notices, and changed-file statements stay with the copies. It grants a patent license that ends if the user files patent litigation over the work. It does not grant trademark rights, and it gives no warranty. That is not a license block. Platform terms were not treated as the open-source license.

Commercial: the open-source library and self-hosted server are free to run under Apache-2.0. Mem0 Platform is a separate hosted service. On 2026-11-15 the pricing page listed a Free plan and a Custom plan. Free includes unlimited end users. For the first 30 days it includes 10,000 adds and 1,000 retrievals a month, with model calls paid by Mem0. With the customer's own LLM key, the page lists 50,000 adds and 10,000 retrievals a month. Usage past those limits is usage-based with a monthly cap the customer sets. The pricing FAQ says the extra rate is shown when that billing is turned on, so the dollar rate is unverified. The same FAQ says recommended provider models cost about $3.55 to $5.34 per 1,000 adds, billed by the provider, not by Mem0. Custom covers higher volume, graph memory, user profiles, Dream consolidation, advanced analytics, private Slack, SSO, audit logs, SLA, on-prem deployment, and custom integrations. Old Starter, Growth, and Pro plans are no longer sold to new accounts. Exact Adrian Mind usage is unverified. This research created no account and spent no money.

Activity: at check time the GitHub API showed 68,939 stars, 8,202 forks, 252 subscribers, and an open-issue count of 945. That count includes pull requests. The releases page navigation showed 473 issues and 466 pull requests in the same pass. `created_at` was 2023-06-20T08:58:36Z. The site star widget still said 62,590, and the about page said 66,000+ stars, so those marketing counters lag the API. npm recorded 221,719 downloads of `mem0ai` from 2026-11-08 through 2026-11-14. PyPI Stats recorded 506,380 downloads of `mem0ai` in the last week and 2,499,246 in the last month. Y Combinator lists the company as founded in 2023, batch Summer 2024, team size 10, San Francisco, status Active. The about page says $24 million raised. That figure was not rechecked against a filing.

Runtime: a Python library and a TypeScript library, plus an optional self-hosted REST server. The documented library path is `Memory()` after `pip install mem0ai` or `npm install mem0ai`. Defaults for the library are OpenAI `gpt-5-mini`, OpenAI `text-embedding-3-small`, local Qdrant at `/tmp/qdrant`, and SQLite history at `~/.mem0/history.db`. The self-hosted path is Docker Compose under `server/`, with the API on port 8888, the dashboard on port 3000, and Postgres plus pgvector. Auth is on by default. The server refuses to start without `JWT_SECRET` when auth is enabled. The hosted platform is a third path and needs `MEM0_API_KEY`. None of this was executed.

Install size: not measured on disk, because nothing was installed or pulled. The PyPI 2.2.1 wheel is 351,907 bytes and the sdist is 256,091 bytes. The npm 3.3.1 record reports an unpacked size of 4,136,943 bytes across 14 files. Those figures do not include Qdrant, Postgres, Docker, OpenAI, or the optional vector-store and NLP extras. The docs say a local `sentence-transformers` provider pulls in PyTorch and is kept out of the default image because it is about 2 GB. GitHub reports the repository size as 69,859 KB. That is not an installed footprint.

Dependencies: the Python 2.2.1 record requires Python `>=3.10,<4` and depends on `httpx`, `openai`, `posthog`, `protobuf`, `pydantic`, `pytz`, `qdrant-client`, and `sqlalchemy`. Vector stores, extra LLMs, and spaCy are extras. The npm 3.3.1 record requires Node `>=18` and depends on `zod` `^3.24.1`, `uuid`, `axios`, and `openai`. Its peer dependencies, including `pg`, `redis`, and `better-sqlite3`, are optional. The published npm scripts are build, test, and example scripts. They do not include `preinstall`, `install`, or `postinstall`. Self-hosting adds Docker, Postgres with pgvector, and a provider key. Transitive dependency risk was not audited.

Security: GitHub lists one published advisory, [GHSA-5324-3w58-qpp2](https://github.com/mem0ai/mem0/security/advisories/GHSA-5324-3w58-qpp2), also CVE-2026-116575. It is a medium cross-tenant conversation leak from an unescaped session-scope delimiter. It was published 2026-10-20T17:17:59Z, updated 2026-10-26T20:12:08Z, and is not withdrawn. The recorded vulnerable ranges are Python `mem0ai` at or below 2.0.0, patched in 2.0.18, and npm `mem0ai` at or below 3.0.0, patched in 3.1.6. The current packages are outside those ranges. At tags `v2.2.1` and `ts-v3.3.1`, the session-scope builders percent-encode `%`, `&`, and `=` before joining the key. That is the encoding the advisory suggested. No new vulnerability scan was run. `main` is 14 commits ahead and includes later Dependabot bumps, including a 2026-11-06 commit for CVE-2026-109461 in an OpenClaw integration lockfile. Whether any of those later findings still affect the published 2.2.1 wheel or 3.3.1 tarball is unverified. SECURITY.md says fixes go to the latest published version of each package.

Secrets: a hosted client needs `MEM0_API_KEY`. The library default needs `OPENAI_API_KEY` for the LLM and the embedder. The xAI example still sets `OPENAI_API_KEY` for embeddings while using `XAI_API_KEY` for the chat model. Self-hosting needs `JWT_SECRET`, a provider key, and optionally `ADMIN_API_KEY`. `AUTH_DISABLED=true` is documented for local development only. The README and agent-signup page tell an agent to run `mem0 init --agent`, which creates a platform account and writes an API key to `~/.mem0/config.json`. That command was not run. Python telemetry is on unless `MEM0_TELEMETRY` is false. At tag `v2.2.1` it posts anonymous events to PostHog at `https://us.i.posthog.com`, including a local user id, OS details, and the configured provider class names. No secret was read or written for this check.

Integration: Adrian Mind does not import Mem0. The product `package.json` has no `mem0ai` dependency, and a repository search outside `node_modules`, `.git`, and `upstream` found no Mem0 reference. Adding it would be a new memory store beside the current preview, not an upgrade of Chat, Build, or Speak. The hosted path would send conversation text to Mem0. The library path would store history locally and send text to the configured model provider. It was not added.

Compatibility: the product TypeScript range is `^5.7.0` and `zod` is `^4.4.0`. The product manifest has no `engines` field. The sandbox Node is v22.23.4, which meets the npm package's `>=18`. The sandbox Python is 3.12.3, which meets the PyPI range, but the preview is not a Python app. npm `mem0ai` depends on `zod` `^3.24.1`, so a later install could nest Zod 3 beside the product's Zod 4. That was not tested. The docs include an xAI provider example for both Python and TypeScript, using model `grok-4.3` and `mem0ai/oss` on the TypeScript side. The LLM overview page's TypeScript list does not name xAI, so those two pages disagree. Default embeddings remain OpenAI `text-embedding-3-small`. Whether the saved Grok key can replace that embedder is unverified. The product's coding model name, grok-4.7, was not tested against the documented `grok-4.3` example.

Risks: memory writes store user and agent text, and the library default sends that text to OpenAI for extraction and embeddings. A hosted trial would also store it outside the current preview database. The agent-signup command creates an unowned platform account and a local API key without an email, so it must not be run as part of a review. Telemetry is on by default in the Python tag. The published session-scope advisory is patched before the current packages, but `main` has later dependency bumps that are not in those packages. The README says the April 2026 benchmark scores reflect the managed platform, and open-source numbers should be similar, not identical. Graph memory, user profiles, and Dream are custom-plan features. No code review of either SDK was done.

Maintenance: the mem0ai organization publishes the repository. The newest published SDK tags are 2026-09-25, and `main` moved again on 2026-11-06. SECURITY.md says the maintainers acknowledge a private report within 72 hours and ship security fixes on the latest published version of each package. Support beyond that policy page is unverified. Y Combinator lists the company as active. That is not a support contract.

Rollback: do not add `mem0ai`, `mem0-cli`, or `@mem0/cli`, and do not run `mem0 init`, Docker Compose, or a hosted signup. If a later trial does, remove the added package from the manifest, delete `~/.mem0` and the local `/tmp/qdrant` path created for the trial, stop the Compose stack, and delete its volume. A hosted trial would also need the created project or agent account deleted. Nothing was installed, so there is no package, volume, or account to remove.

Classification: evaluation-only. Identity is confirmed. The Apache-2.0 license does not block review. The one published advisory names patches before the current Python 2.2.1 and Node 3.3.1 packages, and those tags contain the session-scope encoding. It is not approved and not installed.
