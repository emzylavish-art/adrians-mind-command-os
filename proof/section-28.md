# Section 28 — Release artifact boundary

Written on 2026-11-14 because the original section never arrived. This is not recovered owner text. It does not authorize a deploy, a signing key, a purchase, or a Windows installer.

28.1 A later release pipeline may record a version, a commit, and an artifact name. It may not store secrets, signing keys, or the owner's personal files.

28.2 Until a computer is paired, the only storage an action may use is the hosted workspace. A color change on Eve's computer is not a desktop change.

28.3 The unnumbered page that arrived before Section 30 prefers published packages, APIs, and official releases. It is not Section 28, and it is not permission to install those packages.

28.4 Cleanup from the stored 29.5 rule still applies: do not delete user projects, source files, important configuration, backups, or model files in use.

28.5 This section does not close Issue 48 or blueprints 92, 93, or 94.
