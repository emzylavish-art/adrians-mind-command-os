# Implementation map

Every pasted section is listed here. Implementation has started only where a local change can be tested without a deploy, a purchase, or a Windows package. Nothing is marked done unless a preview proof or a test exists. This is not a completion report.

## Already in the local preview

Speak talks to the system and shows the saved face, but it cannot press the stop. The microphone stays in this tab and stops when the tab closes. The emergency stop is owner-only. The hosted workspace can read, write, and delete one demo file, and run one approved terminal command, after you approve that exact action. Build uses that hosted workspace and does not need a paired PC. Grok and Voice stay connected. Eve’s face is the saved `eve-idle.jpg`. Her body is a clothed figure, not a finished person. Typing to her changes the background on her own computer immediately. That does not change a Windows desktop. The Agents page shows nine department bots with one orchestrator and the same memory. They are not installed third-party tools, and they cannot use a mouse, a keyboard, or the Windows desktop.

## Starting now

The intelligence layer is the active implementation. The body must read as an adult woman: connected neck, shoulders, waist, hips, arms, and legs, with the saved face in front and the shoulders behind the face. That work stays in the existing rig. It is not a new character and not a Windows app. The live background is `projectFromSpeech` in `src/lib/mind/eve-projection.ts`. It is proven only on the local preview.
