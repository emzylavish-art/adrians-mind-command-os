# Reference interface notes

These are public pages read on 2026-11-14. Login walls were not crossed.

- ChatGPT settings: https://learn.chatgpt.com/docs/reference/settings
  Groups: General, Profile, Keyboard shortcuts, Notifications, Appearance (theme, accent, fonts), Personalization, Memories, Archived chats, Browser, Computer Use.
  Mistake to avoid: one flat settings list that mixes appearance, account, and connections.

- Perplexity account settings: https://www.perplexity.ai/help-center/en/articles/10352993-account-settings
  Groups: Account, Preferences, Personalization, Assistant, Notifications, Usage and credits, Connectors, API Platform.
  Connectors use search plus Connected / Available filters.
  Mistake to avoid: showing every unconnected service as a card beside the ones that are connected.

- Grok content settings: https://grok.com/user-feature-controls-static
  Public page shows a single Content Settings control. Help pages place Data controls under Settings.
  Call notes: https://grok.com/release-notes describes a call screen with a voice picker, separate from the chat.

- Manus connectors: https://manus.im/docs/integrations/connectors
  Catalog of 416 connectors, grouped by category, with App, MCP, and API key types. Search, then connect. A connector is not enabled until the person approves.
  Mistake to avoid: generic cards with no real link and no distinction between connected and available.

- Claude: https://claude.ai was not fully read in this pass. Public pattern from the product is a chat column with settings in a separate account menu, not mixed into the conversation.

## Five-site pass, 2026-11-14

Login walls were not crossed. These notes are only what that pass actually saw or cited.

- ChatGPT public settings is one page with General and Data controls. Connectors are a separate Plugins catalog, not settings rows. Source: https://chatgpt.com/settings
- Grok's live settings page was not visible. Docs list connectors as built-in, catalog, and custom MCP rows. Voice stays on the composer. Source: https://docs.x.ai/grok/connectors
- Claude's signed-in settings did not load. Public help lists Appearance, Your Claude, Capabilities, Privacy, and Wellbeing as separate groups. Connectors are cards on Plugins, not a settings section. Source: https://support.claude.com/en/articles/17740565-manage-plugins-skills-and-connectors-from-one-plugins-page
- Perplexity settings did not render. The public plugins page is a searchable card catalog grouped by the kind of work. Source: https://www.perplexity.ai/computer/plugins
- Manus settings and plugins were behind login. Public docs use collapsible connector categories. Custom MCP is a separate create path. Source: https://manus.im/docs/integrations/connectors

Applied here: unconnected plugins stay behind Show, then open as category groups with search. Custom MCP stays in Kimi links. Scheduled jobs are not listed inside the Settings connector group. Grok and Voice stay in Connected. No citation tabs were added, because no answer body was visible on the reference sites.
