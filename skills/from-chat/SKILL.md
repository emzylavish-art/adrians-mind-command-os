# Capture a workflow

1. Check that the account owns the conversation and that its history and memory-saving settings permit learning. Skip temporary conversations.
2. Identify the operation that actually finished. A proposed action, an incomplete response, and a provider's claim of success each need separate execution evidence.
3. Write a short title, the circumstances that call for the procedure, and a sequence that works with fresh inputs. Use role and operation names. Omit chat text, account identifiers, credentials, personal notes and retrieved material.
4. Group repeated observations of the same procedure. Show the latest observation and how many completed examples support it. Revise the instructions only when their procedure changes.
5. Present the result in Skills for review or export as SKILL.md. Use the account's existing version review, fixture validation and activation flow for Chat or Build. Apply the current session's permissions whenever the skill is reused.
