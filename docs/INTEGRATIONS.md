# Integrations

| Integration | State | Notes |
|---|---|---|
| Grok chat | Implemented, not live-tested this change | Existing send path. |
| Other model vendors | Blocked | No keys stored. |
| Gmail | Blocked | Records only. |
| Google Drive, Docs, Sheets, Slides | Not built | Named on a screenshot. No OAuth. |
| GitHub and Notion | Not built | No new adapters. Existing platform connectors are outside this app. |
| Web search | Blocked | Needs `MIND_SEARCH_ENDPOINT` and `MIND_SEARCH_KEY`. |
| Page inspect | Implemented with limitations | Local Chromium driver. |
| REA doctor and file inspect | Implemented, environment blocked | Doctor is unhealthy. |
| Image and video | Blocked | Not called. |
| HP laptop | Blocked | No device pairing. |
| Zapia | Deferred | Not built. |

Oak Bridge and BridgePoint are not integrations of this app. They are not opened.
