# Arcanum AI Security Resource Hub — Learning Path

**Source:** [Arcanum AI Sec Resource Hub](https://arcanum-sec.github.io/ai-sec-resources/)  
**Purpose:** Hands-on practice attacking AI chatbots and agents so defenses can be built correctly in personal and professional systems.

## Why This Matters for Adrian’s Mind Command OS
The same techniques used in these labs (prompt injection, tool misuse, goal hijacking, memory poisoning) are the threats that will eventually target agent systems like Astra and ZAPI. Learning the attack side first creates stronger, more realistic defenses.

## Recommended Starting Sequence

### Level 1 — Fundamentals
1. **Gandalf (Lakera AI)** — Progressive prompt injection levels. Builds intuition for how language models can be manipulated.
2. **Broken LLM Integration App** — Shows common real-world integration flaws (Direct/Indirect Prompt Injection, Prompt Leaking, P2SQL, LLM2Shell).

### Level 2 — Agent-Specific Attacks
3. **Hack The Agent** — Interactive platform focused on prompt injection, jailbreaking, and AI manipulation against agentic systems.
4. Other agent/MCP labs listed on the hub (AgentDojo, Damn Vulnerable MCP, etc.).

### Level 3 — Automation & Scale
- Tools: Garak, PyRIT, Promptfoo, FuzzyAI
- Competitions: HackAPrompt, Gray Swan Arena, etc.
- Bug bounty programs (Anthropic, OpenAI, Google Gemini, etc.) once comfortable.

## Integration With Decision Models & Self-Improving Skills
- Use decision models to classify lab results and route findings into skill files.
- After completing a lab, have the agent create a skill that captures the attack pattern and the corresponding defense.
- Curator can later consolidate similar attack/defense skills.
