# Lenis

## Role
Smooth scroll for websites. The page should feel finished while it moves, not like a default browser scroll with animation pasted on top.

## Installed
- Source: `upstream/lenis`
- Package: `lenis` 1.3.27 in `tools/website`
- Site use: add `lenis` to the website being built, and drive scroll-linked motion through GSAP.

## Limits
Lenis is the scroll. It is not the animation library and it is not the visual design.
