# Motion

## Role
React section animation for websites. The package is `motion`. The clip calls it Framer Motion. It is a website-team package.

## Installed
- Package: `motion` 14.9.1 in `tools/website`
- Official source: https://github.com/motiondivision/motion
- Use it so sections move. GSAP still owns long timelines. Lenis still owns smooth scroll.

## Limits
Do not add motion to a page that already has a GSAP timeline doing the same move. Do not claim the page is animated because the package is installed.
