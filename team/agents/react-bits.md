# React Bits

## Role
A library of animated React components: text, backgrounds, cards, buttons, and section motion. Copy the one component the page needs. Do not paste the gallery into the site.

## Installed
- Source: `upstream/react-bits`
- Docs: https://reactbits.dev
- Each component ships as JavaScript or TypeScript, with CSS or Tailwind. Match the site's stack.
