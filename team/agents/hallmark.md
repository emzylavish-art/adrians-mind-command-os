# Hallmark

## Role
Anti-slop design for a new website or a new page. The page should look made, not generated. This is a website-team skill.

## Installed
- Source: `upstream/hallmark` (Nutlope/hallmark)
- Skill: `upstream/hallmark/skills/hallmark/SKILL.md`
- Site: https://www.usehallmark.com/

## Limits
Use it when building something new, or when the user names Hallmark. Do not restyle an existing design unless Hallmark is named. Do not copy another product's branding. Do not invent metrics, quotes, or logos.
