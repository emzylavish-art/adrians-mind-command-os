# Character plates

These JPEG plates were generated for Adrian’s Mind Command OS. They are original presentation assets for the in-app canvas renderer.

- Not a Ready Player Me, VRM, or commercial digital-human SDK asset.
- Not a download of a stock photograph or a third-party GLB.
- Commercial use inside this product is intended by the owner. There is no third-party attribution requirement.
- Do not treat a plate as a licensed face rig. A future vendor model needs its own license note before it replaces these files.

| Character | Files | Notes |
|---|---|---|
| EVE | `neutral`, `full`, `listen`, `thoughtful`, `concerned`, `smile`, visemes `aa` `ee` `oo` `mm` | Full body is upper-to-feet, used only in full framing while idle. |
| Liora, Iris, Luna, Aurora | `neutral`, viseme `aa` | Open vowels use `aa`. Closed consonants stay on the closed mouth unless `mm` exists. |

Paths are referenced from `src/lib/mind/characters/index.ts`. The renderer loads only the selected character.
