Connection

Paste the https address printed by the tunnel window, not 127.0.0.1. Paste the line from the secret command. Both stay in this browser.

Find the address in the tunnel window. Find the key with the secret command on the PC. Save connection stores both in this browser, then reads status, config, opt-outs, and audit. Success says Live. A wrong key, a failed read, or a closed tunnel stays Not connected and writes nothing.

Service controls

Start resumes bookkeeping. Pause holds new work. Stop ends the service until Start is pressed again. Each button waits for the PC to accept the key.

Weights are unknown until the PC answers. A missing Jeff file keeps an ordinary inbound at weights_unavailable. That writes a local row and sends nothing.

Check asks the PC. It does not download or replace anything. An install happens only after the file hash matches and the PC receives the word update.

Accounts

Up to ten accounts. Start, Pause, and Stop affect only that account. Resume is accepted only after a kill, and only when the button sends the word resume. Headed login opens one window at a time.

Limits & timing

Ceilings cap how many outbound rows are allowed. Timing sets the random gap, in seconds. Neither uses one fixed interval. Apply writes only after the PC accepts the key.

Installation

The software is the Adrian-Social-USB folder. These scripts are the installer. They do not connect this page by themselves.

Download install.ps1 Download launch.bat Download stop.bat Download the steps

Copy the whole folder onto the EliteBook, then run install.ps1 from that folder. A download of these scripts alone is not the software. This site cannot hold the Dev weight file. The Jeff files were not downloaded because the public host returned authentication required.

After launch, the PC must show a listener on 127.0.0.1:8765. The tunnel command must be cloudflared tunnel --url http://127.0.0.1:8765. If it mentions port 9222, stop. Paste the https address and the local secret into Connect. Do not paste the secret into chat. The page stays Not connected until those four reads succeed.

Reply rules

Write means a local database row. Send means the saved session confirmed a line.

Wrong key

The PC rejects the call before any read. Write: no. Send: no.

Failed read

One of status, config, opt-outs, or audit fails. The page does not mark Live. Write: no. Send: no.

Closed tunnel

The phone never reaches the PC. The PC does not see the click. Write: no. Send: no.

Clean Approve, not confirmed

All six checks pass, then the session cannot show the line. Write: a failure row. Send: no.

Clean Approve, confirmed

All six checks pass and the saved session shows the line. Write: yes. Send: yes, that line only.

weights_unavailable

Jeff is not loaded. The inbound line is stored and the contact is not locked. Write: yes. Send: no.

Challenge pause

The account is marked killed. There is no automatic resume. Write: yes. Send: no.

Permanent stop

A clear stop locks the contact. An ordinary toggle cannot clear it. Write: yes. Send: no.
